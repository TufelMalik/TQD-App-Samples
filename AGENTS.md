# Project Instructions: TQD App Sample

## Automated UI/UX & Compose Workflow Protocol
Whenever any prompt or query pertains to **UI development**, **screens**, **theming**, **visual styling**, **animations**, or **Jetpack Compose**:
- **Auto-activate and strictly follow the installed project skills**:
  - `ui-ux-pro-max` for design system tokens, color palettes, and visual hierarchy.
  - `mobile-ui-ux-designer` for mobile ergonomics, interaction models, and screen state matrices (loading, empty, error).
  - `compose` (`compose-ui`, `compose-architecture`) for native Kotlin Jetpack Compose implementation, MVI pattern, and strong skipping stability.
- **Do not output generic, unstyled, or template-like UI.**
- **Preserve zero business logic in Composable functions.**
